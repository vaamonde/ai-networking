🗓️ **AULA 02** — Engenharia de Prompt para Profissionais de **Redes de Computadores**

🎯 **Objetivo da aula:** Ensinar as técnicas básicas de conversar com a IA, transformando-a em ferramenta profissional.

🧠 **Conteúdo da Aula:**

1. O que é prompt
2. Prompt ruim × prompt bom
3. Elementos de um bom prompt:
  - Papel
  - Contexto
  - Objetivo
  - Restrições
4. Prompt como ferramenta de trabalho
---

📝 **Metodologia:**

1. Exposição dialogada (conversação, perguntas e respostas)
2. Brainstorming (tempestade de ideias)
3. Experimentação guiada (laboratório prático)
---

💻 **Atividade prática**

1. Criar prompts para:
  - Diagnóstico de falha de rede
  - Explicação de erro técnico
  - Checklist de troubleshooting (solução de problemas)
  - Refinar prompts com base nos resultados
